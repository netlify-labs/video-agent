Video Agent

Have your agent set it up

Copy this prompt into Claude Code, Codex, Cursor or another coding agent that can run commands on your computer. It sets up your own Video Agent in your Netlify team: a private copy of the repo on your GitHub, a Netlify project, its settings and the first deploy.

Or use the Deploy to Netlify button 
Set up Video Agent for me in my own Netlify team.

Video Agent (https://github.com/netlify-labs/video-agent) is an open-source app that turns a prompt into an MP4. A deployment is one Netlify project connected to a GitHub repo that I own. Do the whole setup yourself and stop only where this prompt says to ask me or wait for me.

ASK ME FIRST, in one message:
1. Which Netlify team to use. List my teams if you can (`npx netlify api listAccountsForUser`). The team needs a credit-based plan with Agent Runners: any project in it shows an "Agent Runs" tab. A video costs about 90 to 210 AI credits.
2. Who can sign up: my company's email domains, comma-separated (like acme.com), or invite-only.
3. The first admins' email addresses, comma-separated.
4. Which GitHub account or organisation gets the private copy of the repo, and its name (default: video-agent).

RULES:
- Never print, log or commit a token. Never ask me to paste a token into this chat.
- Create exactly one GitHub repo and one Netlify project. Change nothing else in my accounts, and ask before you delete anything.
- If a step fails, show me the error and what you tried. Don't work around a permission you weren't given.

STEPS:
1. Check the tools: git, Node 24 or later, the GitHub CLI signed in (`gh auth status`) and the Netlify CLI signed in (`npx netlify status`). If I'm not signed in, run `gh auth login` or `npx netlify login` and wait while I finish in the browser. If these tools can't be installed here, stop and send me to the Deploy to Netlify button in the repo's README instead.

2. Copy the repo to my GitHub:
   git clone https://github.com/netlify-labs/video-agent.git video-agent
   cd video-agent
   git remote rename origin upstream
   gh repo create <owner>/<name> --private --source . --remote origin --push

3. Install: `npm ci`

4. The runner token. The app starts agent runs with a Netlify personal access token. Ask me to create one at https://app.netlify.com/user/applications (ideally signed in as a separate Netlify account that I've invited to the team, because anyone who can read the project's environment can use it) and to save it myself to ~/.video-agent-runner-token. Wait until I say it's there. Read it only inside the commands below.

5. Create the project and save its settings:
   RUNNER_API_TOKEN="$(cat ~/.video-agent-runner-token)" ALLOWED_EMAIL_DOMAINS="<answer 2>" ADMIN_EMAILS="<answer 3>" OPENVERSE_SETUP=no npm run setup -- --team <team slug>
   This creates the project, saves the three settings as variables of that project only, creates VIDEO_AGENT_RUN_SECRET and turns on Identity. Then it stops and prints the project's id and an address ending in /configuration/deploys.

6. Connect the repo. Ask me to open that address, choose "Link repository" and pick the repo from step 2, keeping the build settings it suggests. Only I can do this: it installs Netlify's GitHub app. Wait until I say it's done.

7. Deploy and check: run the command from step 5 again with `--site <project id>` in place of `--team <team slug>`. It builds production from Git, which also creates the database, then prints the setup checks. When it finishes, delete ~/.video-agent-runner-token.

8. Fix what the checks mark as failed, where you can, and check again with `curl -s "https://<site>/api/health?fresh=1"`. A variable only reaches the app after a new deploy.

9. Tell me what's left for me to do in the browser:
   - With company domains: in Project configuration > Identity keep registration open and autoconfirm off. Then I sign up at https://<site> with an admin address and confirm it from the email.
   - With invite-only: in Project configuration > Identity set registration to "Invite only" and invite each admin address from the Identity tab. Then I accept the invite from the email.
   - Open https://<site>/setup. It lists anything still missing.

10. End with a summary: the GitHub repo, the Netlify project, the site address, which checks passed, and anything you couldn't do or couldn't verify.

LATER, only if I ask: my brand (fonts, colours, logos, product facts) goes in context/ in the new repo. docs/guides/deploy.md in the repo covers Sign in with Netlify, roles, the trust model and every setting.

What you'll be asked

  • Which Netlify team, who can sign up and who the first admins are.
  • To create a Netlify personal access token and save it to a file. The agent never asks you to paste it.
  • To link the new GitHub repo to the project in Netlify. It's one screen.
  • To create your admin account when the site is up.

What you need

  • A Netlify team on a credit-based plan with Agent Runners. If a project in the team has an Agent Runs tab, you're set.
  • A GitHub account.
  • A coding agent with a terminal, Node 24 or later, and the GitHub CLI.

Read the prompt before you run it, as you would any script. The same steps by hand are in the deploy guide.
